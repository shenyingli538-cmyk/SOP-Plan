# Dify

## 一句话定位
**开源的大模型应用开发平台（LLM App Platform）**——通过可视化方式搭建、编排、发布 AI 应用（聊天机器人、Agent、RAG 知识库等）。

## 它做什么（核心能力）
- **可视化编排（Workflow/Agent）**：拖拽式工作流，编排 LLM、工具、知识库、条件分支等节点，构建复杂 AI 应用。
- **RAG 知识库**：上传文档构建向量知识库，支持检索增强生成（RAG），让 AI 基于私有知识回答。
- **Agent 能力**：让模型调用工具、函数、联网搜索、API，自主完成多步任务。
- **Prompt 管理与调试**：可视化调试 Prompt、模型参数、输出，快速迭代。
- **模型接入**：支持多种大模型（OpenAI、Anthropic、Claude、国产模型如通义/智谱等）与本地模型（Ollama）。
- **发布与集成**：一键发布为 Web 应用、API、嵌入网页；支持团队协作、日志与监控。

## 工作流价值
- **大幅降低 AI 应用开发门槛**：不写大量代码，也能用可视化方式快速搭出聊天机器人、知识库问答、Agent 应用。
- **RAG 开箱即用**：内置向量库与知识库，省去自行搭建向量数据库 + 嵌入 + 检索的繁琐。
- 从原型到发布一体化：可视化搭建即得到的 Web 应用 / API。
- 开源可自托管，数据可控。

## 成本与风险
- **学习成本**：中，可视化编排概念（节点、工作流、RAG、Agent）需理解，但比纯写代码门槛低。
- **付费/成本**：开源版可自托管（免费），但要自己承担资源与模型 API 费用；云版（付费托管）按套餐；模型调用本身有 token 成本。
- **性能与复杂需求**：超大规模、复杂业务逻辑、深度定制时，可视化编排可能不如纯代码灵活。
- **生态/版本**：更新快，需关注版本演进；依赖模型 API 的质量与成本。

## 建议
- 是**想快速搭建 AI 应用（聊天机器人、知识库问答、Agent）、尤其看重可视化 + RAG + 开源自托管** → 非常值得加入，是当前知名的开源 LLM 应用平台之一。
- **只需轻量调用 LLM、或已有编码化 AI 工作流** → 可用更简单的 LangChain/编码方案，Dify 可能偏重。
