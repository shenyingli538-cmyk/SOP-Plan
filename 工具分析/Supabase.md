# Supabase

## 一句话定位
开源的**后端即服务（BaaS）**平台，定位是"开源的 Firebase"，让开发者快速拿到一套完整后端能力。

## 它做什么（核心能力）
- **PostgreSQL 数据库**：基于真正的 Postgres 的关系型数据库，支持 SQL、关系建模、JSON（JSONB）。
- **认证（Auth）**：开箱即用的用户注册/登录，支持邮箱、OAuth、手机号，会话与权限管理。
- **实时订阅（Realtime）**：数据库变更实时推送到前端，适合聊天、协同、直播类应用。
- **存储（Storage）**：文件上传/存储/分发，配合权限控制。
- **自动生成 API**：自动基于数据库表生成 REST 与 GraphQL 接口（PostgREST），前后端联调快。
- **Edge Functions**：基于 Deno 的无服务器函数，处理后端逻辑。
- **开源可自托管**：既可云端托管，也可自行部署到自己的服务器，数据自己掌控。

## 工作流价值（偏开发）
- 大大缩短后端开发周期：数据库 + 认证 + 存储 + API 一次到位，适合快速做产品原型/MVP。
- SQL 能力比 Firebase 强，适合需要复杂查询、关系数据的项目。
- 开源 + 可自托管，兼顾云便利与数据私有。

## 成本与风险
- **学习成本**：较高，需懂后端/数据库基础概念（SQL、认证、权限、部署），非开发背景较难直接上手。
- **付费**：有免费额度，随用量/团队升级付费；自托管则承担运维成本。
- **早期项目风险**：产品迭代快、接口可能有变动，需关注版本与迁移。
- **运维负担**：自托管时需自己维护数据库、备份、安全、扩展。

## 建议
- 是做**开发/AI 应用后端、需要快速上线带数据库/登录/存储的产品** → 很值得加入，能显著提速。
- **纯内容创作 / 非开发工作流、或没有后端需求** → 用不上，无需考虑。
