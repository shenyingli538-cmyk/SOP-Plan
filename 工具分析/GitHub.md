# GitHub

## 一句话定位
全球最大的**代码托管与协作开发平台**（基于 Git 的版本控制系统），也是现代软件开发的"基础设施"。

## 它做什么（核心能力）
- **代码托管与版本控制**：托管 Git 仓库，管理代码版本、分支、合并，历史追溯。
- **协作开发**：Pull Request（PR）、Code Review、Issue（问题跟踪）、多人在同一仓库协作。
- **CI/CD 自动化（GitHub Actions）**：内置自动化构建、测试、部署流水线，push 即自动执行。
- **项目管理**：Projects（看板）、Milestones 等，与代码仓库关联。
- **开源与社区**：全球最大的开源社区，Star/Fork 海量公开项目。
- **集成生态**：与 Linear、Vercel、Slack、众多第三方工具深度集成；Copilot（AI 编程助手）嵌入式。

## 工作流价值
- **现代开发的核心枢纽**：几乎每个开发团队/开源项目都围绕它运转，源码、协作、自动化都在这。
- 与前面分析的 **Linear、Vercel** 天然打通（PR 关联、自动部署）。
- 极大简化团队协作与代码审查，历史透明、可回溯。
- Copilot 等 AI 能力进一步提升生产力。

## 成本与风险
- **学习成本**：中低，需懂 Git 基础（分支、提交、PR）；非技术用户基本用不上。
- **付费**：免费版对开源/个人项目功能齐全；**私有仓库 / 团队高级功能（Actions 分钟数/存储、高级协作）按席位或用量订阅**。
- **网络**：国际服务，国内访问可能不稳定，需代理或加速。
- **数据**：代码存于云端（GitHub），敏感/私有数据需谨慎，可用私有仓库或企业版（GitHub Enterprise/自托管）。

## 建议
- 是**任何软件开发 / 开源项目 / AI 应用开发**的**必备**工具，几乎无可替代——只要写代码、要协作、要自动化，就值得加入。
- **纯内容创作 / 非开发** → 用不上。
