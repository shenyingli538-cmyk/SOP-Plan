# n8n

## 一句话定位
**开源的工作流自动化平台**，用可视化的节点流程图把各种应用、API、AI 模型连起来，自动执行任务。常被称为"自动化界的 Zapier/Make 的开源自托管替代品"。

## 它做什么（核心能力）
- **可视化节点编排（Workflow）**：拖拽节点（触发/工具/条件/循环/转换），画成流程图串联自动化流程，无需写大量代码。
- **海量集成**：内置数百个应用/API 连接器（Google、GitHub、Slack、Notion、数据库、HTTP 请求等），几乎任何有 API 的服务都能接。
- **AI / LLM 节点**：深度集成大模型（OpenAI、Claude 等），能搭 AI Agent（ReAct agent、工具调用）、RAG、聊天工作流——可视为"自动化版的 Dify 胶水"。
- **触发器与调度**：定时、Webhook、事件触发，按需或周期运行。
- **自托管 & 数据私有**：开源可自托管（Docker 一键部署），数据在自己服务器，也可用官方云版。
- **错误处理与监控**：执行日志、重试、错误分支，便于排障。

## 工作流价值（非常契合本套件）
- **把前面所有工具"串"成一个自动运行的整体**：例如 GitHub 事件 → 自动更新 Linear、调用 Dify 生成内容、写入 Obsidian 笔记、发到 Slack。
- **AI 当"胶水"的具体载体**：n8n 的 AI Agent 节点可以让模型自主决定调用哪些工具/API 完成多步任务，把"智能体 + 自动化"合二为一。
- **替代手工搬运**：数据同步、通知、内容生成、上报等重复工作全部自动化。
- 相比 Dify：Dify 专注"构建 AI 应用/知识库"，n8n 专注"自动化流程 + 跨系统集成"，两者可互补。

## 成本与风险
- **学习成本**：中高，可视化编排 + 节点概念需时间，复杂流程仍可能要写少量表达式/代码。
- **资源成本**：自托管需自己付服务器/运维；云版按套餐；频繁 AI 节点调用有 token 费用。
- **维护**：自托管版本需自己更新、备份、保证安全；集成节点可能随第三方 API 变动而失效。
- **稳定性/安全**：自动化把多个系统串起来，需注意权限、密钥管理、防止误操作（无人值守任务）。
- **定位**：面向"会折腾"的用户，纯非技术场景用无代码工具（Zapier/Make）更省心。

## 建议
- 是**想用开源、可自托管、可深度集成 + AI Agent 的自动化引擎** → 非常值得加入，是这套"Obsidian 中枢 + 工具串联"方案的**最佳落地载体**（AI 胶水由 n8n 承担自动化调度）。
- **只想简单自动化、不想维护** → 用云版 Zapier/Make 或 Dify 内置工作流即可；不想要自托管运维就不必上 n8n。

## 在本套件中的角色
> 补位到《Obsidian起点-工具串联方案》：n8n 可在"AI 胶水"层面承担**跨工具自动化 + AI Agent 编排**，把 Step1-7 的传递手动变自动。
