# Notion

## 一句话定位
集笔记、知识库、任务管理、数据库于一体的"全能型工作空间"（All-in-one workspace）。

## 它做什么（核心能力）
- **笔记与文档**：类 Markdown 富文本编辑，支持块（Block）化排版，方便组织长文档、Wiki。
- **数据库**：表格 / 看板 / 日历 / 列表等多种视图，可做任务、项目、内容台账管理（类似轻量 Airtable）。
- **知识库 / Wiki**：页面层级 + 双向链接 + 模板，适合团队知识沉淀。
- **任务与项目管理**：看板、时间线、甘特图，配合数据库做跟踪。
- **协作与发布**：实时多人协作、评论、权限管理；可一键发布为网页。
- **第三方生态**：大量模板、AI（Notion AI）、与众多工具集成。

## 工作流价值
- 把"记录 + 整理 + 管理"收敛到一处，减少工具切换。
- 数据库视图适合做内容/项目/信息的结构化管理。
- 模板丰富，上手即可用。

## 成本与风险
- **学习成本**：中等。块编辑与数据库概念需要熟悉，容易把页面搭得越来越复杂。
- **付费**：个人免费版功能较全，团队/AI/高级协作按席位订阅。
- **网络依赖**：云服务为主，离线编辑有限；国内访问速度可能不稳定。
- **性能**：文档/数据库过大时可能变慢；重度用户常抱怨加载。
- **数据锁定**：数据在自家平台内，导出格式有一定限制。

## 建议
- 工作流中有"知识沉淀 / 项目管理 / 内容台账"需求，且希望**一个工具搞定** → 很值得加入。
- 已有很强惯用的笔记 + 项目管理工具组合，且在意**离线/速度/数据私有** → 可能重叠，需权衡。
