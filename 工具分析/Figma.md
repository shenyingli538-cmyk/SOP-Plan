# Figma

## 一句话定位
基于浏览器的云端协作式界面设计工具（UI/UX 设计、产品原型、设计系统）。

## 它做什么（核心能力）
- **界面设计**：矢量绘图、自动布局（Auto Layout）、组件/变体；适合 App 界面、网站、海报、图表设计。
- **原型与交互**：直接拉线做可点击原型，模拟页面跳转、滚动、交互反馈，用于评审与演示。
- **实时协作**：多人同时编辑同一个文件，光标可见，支持评论、标注、圈图反馈。
- **设计系统**：组件库、样式、变量统一管理，便于团队复用和保持一致性。
- **开发交付**：标注尺寸、导出切图（PNG/SVG）；配合插件可自动生成样式、Design Tokens，衔接开发。
- **第三方生态**：大量插件（图标、插画、AI 生成、内容填充等）+ Dev Mode 等进阶能力。

## 工作流价值
- 产品 / 界面 / 内容视觉类工作的行业标准，协作效率高。
- 免费版对个人够用（草稿文件数有限），团队协作付费。
- 设计 → 开发衔接顺畅，减少"图片沟通"摩擦。

## 成本与风险
- **学习成本**：中等，非设计背景需熟悉图层、自动布局、组件概念。
- **付费**：专业版按席位收费，团队成本随人数上升。
- **依赖网络**：云端与实时协作依赖连接，离线能力有限。
- **不适合**：插画/动画深度创作、复杂平面印刷物料。

## 建议
- 工作流里有"设计界面 / 产品 / 协作评审"这一环 → **值得加入**（尤其是多人协作）。
- 只是轻量制图 → 不必上 Figma，用更轻工具或 AI 生图即可。
