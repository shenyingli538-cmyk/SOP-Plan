# Linear

## 一句话定位
面向产品/研发团队的**现代项目与问题跟踪（Issue Tracking）工具**，主打极速体验与高效流程。

## 它做什么（核心能力）
- **问题/任务管理**：Issue（任务/缺陷）的创建、状态流转、优先级、负责人、截止时间，支持键盘快捷键极速操作。
- **敏捷迭代**：Sprint（迭代）、里程碑、路线图（Roadmap）、周期视图，适合 Scrum/看板流程。
- **多视图**：看板、列表、时间线、日历、里程碑等多种视图切换。
- **与代码/开发集成**：与 GitHub / GitLab 深度联动（PR 关联、提交自动更新状态），与 Slack、Figma 等协作。
- **团队协作**：评论、@提及、通知、项目与团队多级组织。
- **极致性能与体验**：界面响应极快，快捷键驱动，被公认为"做得最顺手的现代项目管理工具之一"。

## 工作流价值
- 大量团队用它替代 Jira，因为**更轻、更快、更好用**，学习成本低。
- 工程师、设计、产品协同顺畅，尤其适合敏捷开发团队。
- 与代码仓库集成能自动更新任务状态，减少人工同步。

## 成本与风险
- **学习成本**：低，界面直观、快捷键友好。
- **付费**：免费版有功能限制（个人免费版），团队按席位订阅（相对 Jira 性价比感知更好）。
- **定位偏研发**：主要服务软件/产品团队，非技术项目管理（如纯运营、传统项目）未必是最优。
- **数据/生态**：是较年轻的工具，深度工作流迁移（从 Jira/其他）需评估，复杂报表能力不如成熟企业工具。

## 建议
- 是**做软件产品 / 研发团队的项目与迭代管理** → 非常值得加入，是近年口碑最好的现代 Issue 工具之一，常用来替代 Jira。
- **非研发项目管理（如运营、传统业务）** → 也可用，但要确认其偏研发的流程是否符合习惯。
