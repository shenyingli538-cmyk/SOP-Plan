# 工具谱系总览（AI 应用开发工作流）

> 关联文档：Figma / Notion / Google Drive / Linear / GitHub / Supabase / Vercel / Apifox / Dify / Browser Use

## 总体判断
这是一条**完整的 "AI 驱动的 Web 应用 / SaaS" 开发工作流**，涵盖从需求管理、设计、开发、后端、接口、部署到 AI 应用层与自动化的全部环节。工具组合非常主流、结构清晰，各层职责分明、重叠较小。

## 分层图谱

### 1. 规划与知识层
| 工具 | 角色 |
|---|---|
| **Notion** | 知识库、文档、内容台账 |
| **Google Drive** | 云存储、文件同步、在线协同（表/文档） |
| **Linear** | 项目 / Sprint / Issue（需求与迭代管理） |

### 2. 设计层
| 工具 | 角色 |
|---|---|
| **Figma** | 界面 / 原型 / 设计系统，设计与开发衔接 |

### 3. 开发与协作层
| 工具 | 角色 |
|---|---|
| **GitHub** | 代码托管、分支、PR 评审、CI/CD（Actions） |
| **Apifox** | API 契约设计、调试、自动化测试、Mock |

### 4. 后端与数据层
| 工具 | 角色 |
|---|---|
| **Supabase** | Postgres 数据库、认证、存储、实时推送、自动 API |

### 5. 前端部署层
| 工具 | 角色 |
|---|---|
| **Vercel** | 前端托管部署、Serverless / 边缘函数、Git 自动部署 |

### 6. AI 应用层
| 工具 | 角色 |
|---|---|
| **Dify** | LLM 应用平台：可视化编排、RAG 知识库、Agent、发布 |
| **Browser Use** | 让 AI 操控真实浏览器，做网页数据采集 / 自动化 Agent |

## 核心 vs 可选

### 核心必需（几乎不可替代）
- **GitHub**：开发基础设施，源码+协作+自动化。
- **Supabase + Vercel**：后端数据/认证 + 前端部署，构成 Web 应用主循环。
- **Dify**：AI 应用层核心，快速落地聊天/知识库/Agent。

### 强烈推荐（性价比高）
- **Linear**：取代 Jira，项目迭代管理。
- **Figma**：产品/界面设计与原型。
- **Apifox**：前后端接口契约 + 自动化测试。

### 视场景而定
- **Notion / Google Drive**：日常知识与文件协同，与已有工具选择有关（见下）。
- **Browser Use**：仅当需要"AI 自动操作网页 / 采集"时才有价值。

## 潜在重叠与注意事项
- **Notion vs Obsidian（你正在用）**：都用 Markdown + 双向链接做知识库。Notion 更偏结构化数据库与团队协同；Obsidian 更偏本地私有。**若已习惯 Obsidian 且重私有，Notion 可视为可选而非必需。**
- **Dify vs Browser Use**：两者都是 AI 自动化，但方向不同。Dify 是"构建 AI 应用"；Browser Use 是"让 AI 操作已有网页"（数据采集 / 执行网页任务）。不冲突，数据采集可用 Browser Use，产品内 AI 用 Dify。
- **Vercel vs Supabase**：Vercel 提供 serverless 函数，但真正的数据库/认证/复杂后端交给 Supabase，二者互补不重复。
- **成本**：均为订阅/按量付费，个人开发可用免费额度起步；AI 相关（Dify 模型调用、Browser Use token）会随用量产生费用，需留意。

## 建议取舍
1. **若目标是做一款 AI Web 应用 / SaaS** → 这套组合**几乎全收**，是主流且高效的底座。
2. **若只想做轻量 AI 应用（不想太重）** → 可先砍掉 Apifox、Browser Use，保留 GitHub + Vercel + Supabase + Dify 四件套起步。
3. **若重数据私有 / 本地化** → Notion 换 Obsidian，Google Drive 换自托管（NAS/Nextcloud），其余保留。
4. **跟进优先级**：GitHub → Supabase → Vercel → Dify 为核心主线；Linear、Figma 提升协作与体验；Apifox、Browser Use 按需补充。

## 一句话结论
这是一条**标准、主流、无明显重叠的 AI Web 应用开发链**。核心四件套 **GitHub / Vercel / Supabase / Dify** 值得优先纳入；其余按你的产品形态与「是否重私有化」选择取舍。
