# Vercel

## 一句话定位
面向现代前端的**云平台 / 部署托管服务**，以极简的部署体验著称（同样以 Next.js 背后公司闻名）。

## 它做什么（核心能力）
- **前端托管与部署**：把 Web 项目一键部署上线，自动分配 HTTPS、CDN、全球节点。
- **与 Git 深度集成**：连接 GitHub 仓库，push 即自动构建、预览、部署到生产；每次 PR 生成独立预览环境。
- **Serverless 函数 / 边缘计算**：支持服务端逻辑（API、Serverless Function、Edge Functions、Middleware）。
- **Next.js 深度优化**：作为 Next.js 官方平台，对静态/动态/ISR/流式渲染等有最佳实践支持。
- **环境变量与配置**：按环境管理密钥、域名、重写规则等。
- **协作与监控**：团队项目共享、部署历史回滚、性能与日志监控。

## 工作流价值（偏开发）
- 部署体验"零配置 + 秒级上线"，省去自己配置服务器/CI 的麻烦，开发→上线非常顺畅。
- Git 集成 + 自动预览，适合团队协作与快速迭代。
- 免费额度对个人项目/学习很友好（Hobby 版）。

## 成本与风险
- **学习成本**：中低，主要面向开发者，需要懂 Git 与基本部署概念；非开发者用不上。
- **付费**：个人免费版够用，团队/企业版（Team/Enterprise）按席位与用量收费；大量 Serverless 调用或大流量会产生费用。
- **平台锁定**：部署与配置绑定其平台生态，迁移到其他托管服务需调整。
- **服务器端能力有限**：它不是"全能后端"，复杂数据库/常驻进程需配合其他服务（如 Supabase）。

## 建议
- 是**开发 Web / AI 前端应用、希望极速上线与 Git 自动化部署** → 非常值得加入，基本是当前前端部署的主流选择。
- **纯内容创作 / 非开发工作流** → 用不上，无需考虑。
