# SOP-06：代码与数据边界

> ← 返回总览：[[现行开发流程SOP-2026-09-07]]

## 代码模块

| 代码模块 | 边界 |
| --- | --- |
| `common-platform`（公共平台代码模块） | 公共任务、文件、幂等、Outbox（事务消息发件箱）、审计、状态和期间原语 |
| `system-center`（系统中心代码模块） | 租户、公司、组织、成员、角色、权限、菜单和平台配置 |
| `auth-center`（认证中心代码模块） | 登录凭据及服务端不透明 Session（服务端会话） |
| `portal-center`（门户中心代码模块） | 门户壳、导航、检索、消息、收藏和传输中心编排 |
| `master-data`（主数据代码模块） | 员工、往来主体、商品、单位、仓库和资金基础档案 |
| `farming-center`（养殖中心代码模块） | 养殖存栏与生产事实 |
| `warehouse-center`（仓储中心代码模块） | 库存余额和不可变库存流水的唯一写入者 |
| `trade-center`（交易中心代码模块） | 采购销售订单与履约来源 |
| `settlement-center`（结算中心代码模块） | 结算、收付款、核销、资金流水和余额的唯一写入者 |
| `report-center`（报表中心代码模块） | 只读正式事实和版本化报表投影 |
| `app-bootstrap`（应用装配启动模块） | 模块装配与运行入口，不拥有业务事实 |

## 强制边界

- 跨模块只能调用公开应用服务；禁止引用他域 Mapper（数据映射器） 或直接读写他域私表。
- 一个正式事实只能有一个 writer（写入者）；consumer（能力消费方） 不得复制第二套余额、流水或权威快照。
- 不新增未受控代码模块。
- 登录使用服务端不透明 Session（服务端会话），不使用 JWT（结构化对象表示法网络令牌）。
- 运行时不使用 `accounting_book_id`（已禁用的运行时会计账簿标识）。
- 已发布 Flyway（数据库迁移工具） 不可修改，新变化只能追加更高版本。
- 测试夹具、SQL（结构化查询语言） 手工直写和私表查询不得替代生产 provider（能力提供方） 或用户真实验收。
