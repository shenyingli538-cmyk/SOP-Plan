# SOP-11：G5（第五门禁）、G6（第六门禁） 与发布

> ← 返回总览：[[现行开发流程SOP-2026-09-07]]

当前活动治理门禁只有 G5（第五门禁） 和 G6（第六门禁）：

- G5（第五门禁）：用户明确批准 `stage → integration/p0`（阶段分支进入第一期集成分支） 后执行，用于 Integration（集成阶段） promotion（晋级） 和跨阶段/业务链验证；不是模块开发前置。
- G6（第六门禁）：用户明确批准 `integration/p0 → release/p0`（第一期集成分支进入第一期发布分支） 后执行，用于 Release（发布阶段） promotion（晋级）、完整发布条件和发布候选验证；不是 Stage（阶段） 模块开发前置。

最终流向：

```
stage/sN    （阶段编号占位符对应的阶段分支模板）
→ 用户批准
→ integration/p0 + G5    （进入第一期集成分支并执行第五门禁）
→ 用户批准
→ release/p0 + G6    （进入第一期发布分支并执行第六门禁）
→ 用户批准
→ main    （进入主分支）
```

采购、销售、养殖三条端到端链分别为：

```
CHAIN-PUR：S2 → S4 → S5 → S6 → S7    （采购业务链：第二阶段到第四、第五、第六和第七阶段）
CHAIN-SAL：S2 → S4 → S5 → S6 → S7    （销售业务链：第二阶段到第四、第五、第六和第七阶段）
CHAIN-FARM：S2 → S3 → S4 → S7    （养殖业务链：第二阶段到第三、第四和第七阶段）
```
