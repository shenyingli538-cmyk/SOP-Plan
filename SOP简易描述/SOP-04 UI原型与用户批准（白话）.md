# SOP-04 UI 原型与用户批准（白话）

> ← 返回简易总览：[[SOP简易描述]]
> 详细规则：[[SOP-04 UI原型与用户批准]]

## 白话

凡是要点界面、有交互的，必须**先做一个能点、能看的原型**给你，你点“同意”才进入正式开发；不同意就改，直到你点头。纯后端不用硬造界面。

## 例子

装修前先用**效果图/样板间**给你看，你说“柜子要原木色”，设计师改了再确认；确认后才正式下料施工。
